## 新增

- 新增直播推流页面的基础交互，支持读取/保存 OBS 与 SRS 配置、获取和重置推流密钥、复制密钥、检测 OBS WebSocket 与 SRS 连通性，并可将推流配置写入 OBS。
- 新增隐私窗口点选能力，可通过独立选择器框选需要加入隐私规则的窗口。
- 新增实验性功能开关，直播推流等验证中能力可统一隐藏侧边栏入口、页面与相关设置。
- 新增主进程、渲染进程与 IPC 契约的模块化结构，为后续功能拆分和测试覆盖打基础。

## 修复

- 修复部分 Windows 环境下开发版无法正常启动、重复启动后窗口看似立即关闭的问题。
- 修复自动更新安装后无法可靠拉起新版本的问题，补强更新完成后的自动重启流程。
- 修复任务栏、开始菜单和桌面快捷方式图标偶发回退为默认图标的问题。
- 修复主题色自定义在切换预设色后丢失、自定义入口缺失以及颜色编号兼容性不足的问题。
- 修复设备状态中网络趋势图与实际延迟方向相反的问题。
- 修复更新中心当前版本标签受更新通道影响、CURRENT 与 LATEST 重复显示以及更新日志展示不一致的问题。

## 改进

- 重构应用窗口、托盘、关闭行为、通知和隐私选择器相关逻辑，提升桌面端启动与后台运行稳定性。
- 重构服务、自启动、设置页和系统一键体检的布局与交互，统一卡片圆角、响应式栅格、状态摘要和展开动画。
- 优化系统一键体检项目，统一服务器连通性与网络延迟基线的检测口径。
- 优化关于页主要开发者卡片，现在可直接跳转到 GitHub 作者主页。
- 拆分渲染端 CSS 与页面脚本，降低单文件体积，提升后续维护效率。

## 工程化

- 新增 CI、构建检查和发布工作流，发布流程会先执行验证与测试，再生成安装包、ZIP 包和 SHA256 校验文件。
- 发布流程现在优先读取 `release_notes.txt` 作为 GitHub Release 正文。
- 新增 IPC 契约、配置合并、服务控制和更新流程的单元测试。
- 扩充 `npm run verify`，增加模块结构、IPC 一致性、CSS 关键类名和文本编码污染检查。
- 补充贡献指南、PR/Issue 模板、发布流程、测试指南、架构文档和 IPC 契约文档。
- 将旧版 SRS 方案、服务端补丁和历史素材迁移到 `_archive_electron_v1` 归档目录。
