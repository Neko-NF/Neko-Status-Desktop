## 修复

- 修复开发版在部分 Windows 环境下无法正常启动、重复启动后窗口看似立即关闭的问题。
- 修复自动更新安装后无法可靠拉起新版本的问题，补强更新完成后的自动重启流程。
- 修复任务栏、开始菜单和桌面快捷方式图标偶发回退为默认图标的问题。
- 修复主题色自定义在切换预设色后丢失、自定义入口缺失以及颜色编号兼容性不足的问题。
- 修复设备状态中网络趋势图与实际延迟方向相反的问题。
- 修复更新中心当前版本标签受更新通道影响、CURRENT 与 LATEST 重复显示以及更新日志展示不一致的问题。

## 改进

- 将直播推流等验证中能力统一纳入实验性功能开关，关闭后会同步隐藏侧边栏入口、页面与相关设置。
- 扩充系统一键体检项目，并统一服务器连通性与网络延迟基线的检测口径。
- 重构服务与自启动、设置页的卡片布局与文字层级，统一 G3 圆角、响应式栅格与展开动画。
- 优化系统一键体检卡片的结果布局、状态摘要与滚动浏览体验。
- 关于页主要开发者卡片现在支持直接跳转到 GitHub 作者主页。
