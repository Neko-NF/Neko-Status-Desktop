## 修复

- 修复自动更新和强制更新下载完成后仍需要用户手动确认安装向导的问题，Windows 安装包现在会以静默模式启动安装。

- 修复设置页直播推流配置只有进入直播菜单后才刷新的问题，现在启动后会主动加载并回写 SRS 配置。
- 修复 SRS 默认公网端口配置，默认使用 `rtmp1.koirin.com`、RTMP `51935`、HTTP API `51985`。
- 修复 SRS API 开启认证后连通性检测失败的问题，服务端会通过安全环境变量代理访问 SRS HTTP API。
