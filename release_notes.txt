# Neko Status v1.5.0-beta.2

> 这是预发布体验版本。经典界面仍为默认；沉静界面需要在实验性内容中手动开启。
> 当前 Windows 安装包尚未进行代码签名，首次运行时可能出现 SmartScreen 提示。

## 新增

- 新增“沉静界面”实验预览：提供更克制的中性表面、紧凑层级与清晰的操作状态，可在设置页和 UI 实验室随时切换或退回经典界面。
- UI 实验室新增界面预览页，并将加载反馈单独放入页签，浏览界面预览时不会启动额外的曲线动画。

## 优化

- 重新整理仪表盘、活动分享、公告、设置、更新等页面的视觉层级、图标与操作反馈，提升深浅主题和高缩放下的可读性。
- CPU 与内存趋势图改为稳定更新，切换主题、外观或刷新指标时不再反复重绘跳动；图表移除背景网格线以减少干扰。
- 应用可见性、关注者、黑名单、关注规则、搜索结果等长列表改为独立滚动，不会再把同一区域的其他卡片拉长。
- 公告、历史记录和健康检查在刷新时会保留当前位置和键盘焦点，减少列表内容更新造成的打断。
- 头像加载失败时会显示本地名称占位，不再留下空白头像。

## 修复

- 修复实验性入口开关可能被重复触发、导致设置状态立即回退的问题。
- 修复动态列表更新时可能重置滚动位置、丢失焦点或造成相邻卡片高度异常的问题。
