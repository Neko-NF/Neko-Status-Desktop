# Neko Status v1.4.0

## 新增

- 新增实验性的“关注动态”功能，可选择公开的应用、关注其他用户并接收应用上线提醒。
- 新增独立后台运行与 Windows 通知支持；活动窗口缩略图须由用户主动开启，默认保持关闭。
- 新增可选的数学曲线加载效果和 UI 实验室，可在实验性功能中单独开启和预览。

## 优化

- 优化启动、更新、公告、设置等页面的加载与按钮反馈，等待状态更清晰一致。
- 优化实验性功能管理，各入口与视觉实验可以独立控制。
- 更新默认在线服务地址，提升新安装和重置配置后的连接一致性。
- 优化托盘退出选项和后台活动功能的暂停、恢复体验。

## 修复

- 修复后台活动功能可能影响更新覆盖或卸载的问题。
- 修复退出登录、切换服务器或关闭实验功能后，活动状态可能未及时撤销的问题。
- 修复部分页面加载动画重复、按钮状态无法正确恢复的问题。
