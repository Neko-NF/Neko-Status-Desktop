# Neko Status v1.3.0-beta.2

## 新增

- 新增更完整的开发者模式调试面板，支持主窗口/面板 DevTools、重载、焦点切换、运行状态快照与诊断信息查看。
- 新增 UIUX 辅助线与元素定位能力，可识别卡片、文字、图标、按钮、输入控件和常见布局元素，并支持复制元素信息。
- 新增应用内主题色取色器，顶部主题菜单与设置页强调色均支持色板、色相滑条、Hex 输入和实时预览。

## 优化

- 优化开发者模式中文菜单、调试开关、后端状态检查和 UI 定位卡片滚动联动。
- 优化默认主题色方案，新增更适合桌面工具场景的系统预设强调色。
- 优化设置页强调色编辑界面，使自定义主题色与默认主题色保持一致的视觉布局。

## 修复

- 修复更新安装后新版本自启动路径，降低被杀毒软件误拦截或启动失败的风险。
- 修复 Windows 快捷方式重复创建问题，避免桌面和开始菜单出现多份入口。
- 修复开发者模式部分界面错位，以及 UI 定位功能只能分析开发者面板、不能分析主界面的问题。
